# Bug 检查与修复

## Bug 分析

提供的代码存在一个公式错误：

**原始代码：**
```python
def calculate_area(radius):
    return 2 * 3.14 * radius
```

这段代码当前实现的是**圆的周长公式**（`C = 2πr`），但函数名称是 `calculate_area`（计算面积），功能与命名不符。

## 修复后代码

圆的面积公式为：`A = π × r²`

```python
def calculate_area(radius):
    return 3.14 * radius * radius
```

## 差异说明

| 项目 | 修复前 | 修复后 |
|------|--------|--------|
| 公式 | `2 * π * r`（周长） | `π * r²`（面积） |
| 乘法项 | `radius` 乘以一次 | `radius` 自乘一次 |

## 正确性验证

假设 `radius = 5`：
- 修复前：`2 * 3.14 * 5 = 31.4`（周长，错误）
- 修复后：`3.14 * 5 * 5 = 78.5`（面积，正确）

另应使用 `math.pi` 代替硬编码的 `3.14` 以提高精度。
