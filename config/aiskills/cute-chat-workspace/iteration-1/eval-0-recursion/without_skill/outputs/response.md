# 🌸 什么是递归呀？🌸

嗨嗨～让我悄悄告诉你一个超级有趣的魔法，叫做「递归」！(≧◡≦)

## 🪞 就像照镜子…

想象一下，你站在两面相对的镜子中间～喵！你会看到镜子里的你，镜子里还有镜子，镜子里的重复世界里还有镜子……一个接一个，无穷无尽！✨

这就是递归的感觉啦！一个东西的方法里，又调用了自己！(｡♥‿♥｡)

## 🧩 举个可爱的小栗子 🌰

比如「叠叠乐」俄罗斯娃娃，打开最外面的娃娃：
- ➤ 里面还有一个小娃娃，继续打开……
- ➤ 再里面还有一个，继续开……
- ✅ 直到最小的娃娃拿不出来为止，就叫「基准情况」啦！

## 📝 代码里长这样～（Python版）

```python
def echo(n):
    if n == 0:               # ← 基准情况！不再继续啦 ⏹️
        return "喵～结束！"
    return f"第{n}层！" + echo(n - 1)  # ← 自己调用自己！🔄

echo(3)
# 第3层！第2层！第1层！喵～结束！
```

每一步都把问题变小一点，直到小到可以直接解决，这个过程好治愈呀～ (◕‿◕✿)

## 🌈 记住两个条件哦！

| 条件 | 含义 |
|------|------|
| 🔁 **自己调用自己** | 函数里面调用了自己 |
| 🛑 **有出口（基准情况）** | 必须有个停止条件，不然会一直跳下去呀！！Σ(°△°|||) |

## ⚠️ 小提醒～别跳无限循环哦！

如果没有基准情况，递归就会像停不下来的旋转木马一样……监督老师快来救救我呀！😱😱😱
要在代码里一定要写好出口嘛～ (⁄ ⁄•⁄ω⁄•⁄ ⁄)

## 🎉 总结一下

> **递归 = 把大问题拆成一样的小问题 + 一个不再拆的终点**

就像剥洋葱，一层一层，直到露出最里面的核心～洋葱舞 🧅💃
