```python
# 可变参数
# 可变位置参数[打包成元组]
def test1(*args):
    print(args)


test1("你可以放多个参数", 1, 2, 3)  # --> ('你可以放多个参数', 1, 2, 3)

# 可变关键字参数(在形参名前加**)[打包成字典]


def test2(**kwargs):
    print(kwargs)


test2(
    a="你可以放多个关键字参数", b="game", c=1
)  # --> {'a': '你可以放多个关键字参数', 'b': 'game', 'c': 1}


# 可变位置参数, 可变关键字参数, 可以同时使用, 但必须先写可变位置参数
def test3(*args, **kwargs):
    print(args)
    print(kwargs)


test3(1, 2, 3, a="4", b="5")
# 输出结果
# (1, 2, 3)
# {'a': '4', 'b': '5'}
```
# 可变位置参数, 可变关键字参数,也能和其他类型的参数一起使用
```python
# 顺序大概是这样子, 位置参数, 可变位置参数, 关键字参数, 可变关键字参数
def test4(a, b, *c, c2='go' **d):
	print(a)
	print(b)
	print(c)
	print(c2)
	print(d)

test4('你好', 'gay', '可变位置参数', 1, 2, 3, c='ubuntu', l1='可变关键字参数', l2=1)
```

return关键字: return会*结束函数执行*, 并把return后面的*值*, 作为**函数的返回值**
```python
def add(a, b):
	answer = a + b
	return answer
	# 这里可以直接写成return a + b, 如果这样子写answer就没有用了
result = add(100, 200)
# 这里result的返回值就是300
```
